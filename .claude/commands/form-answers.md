# Prepare application-form answers

Establish the active profile using `CLAUDE.md`. Read the exact posting, questions,
word/character limits and the candidate's source profile and writing preferences.
Follow `../skills/job-application-assistant/08-application-forms.md`. For an existing
application, use its tracked archive and submitted documents as consistency checks.
Ask for missing questions or hard limits; never infer personal eligibility answers.

Prepare supported answers, count words/characters programmatically, and provide
counts with each answer. Save `form-answers.md` in the selected application's
archive, or `<profile>/application-forms/<safe-role-name>.md` if no application is
tracked. Keep every answer in the active profile. Preparing answers does not
submit them. Translate this command to `$job-form-answers` in Codex.
